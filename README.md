# Controls
- WASD
- Shift to sprint
- Control to sneak
- E to interact
- There is controller support, but I forgot what the controls were.

# Gameplay
- There are 3 levels. In all levels, your goal is to pickpocket each target and then leave the store without getting caught.
- NPCs have directional vision. It is different for each npc, with some ranging as low as 45 degrees to as high as 180.
- Pickpocketing in front of an NPC increases their suspicion level.
- Hitting a wall in the pickpocket minigame increases all NPCs suspicion levels.
- Some NPCs are more suspicious than others, and may retain a higher level of suspicion when activity is low.
- If any NPC reaches 100% suspicion, you will be caught and lose the level.
